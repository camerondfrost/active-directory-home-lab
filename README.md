# active-directory-home-lab
This project documents my hands-on practice building and administering
a Windows Server Active Directory environment using VirtualBox.

## Overview
This repository documents my hands-on practice building and administering a Windows Server and 
Active Directory environment using VirtualBox.

The lab was created to develop practical skills relevant to entry-level IT Help Desk and IT Support roles,
including Active Directory administration, user and access management, Windows troubleshooting, networking,
and DNS.

## Lab Environment
 - VirtualBox
 - Windows Server 2022
 - Windows 11 
 - Active Directory Domain Services (AD DS)
 - Domain Controller
 - DNS
 - IPv4 networking

## Lab Configuration
The lab consists of a Windows Server 2022 virtual machine configured as a Domain Controller and a
Windows 11 client machine joined to the domain.

I manually configured IPv4 networking on the server and testing connectivity between the Domain Controller,
DNS services, and the Windows client.

## Active Directory Administration
I practiced the following Active Directory tasks:

- Create and manage user accounts
- Create and manage Organizational Unites (OUs)
- Organizing users into department-specific OUs
- Create and manage security groups
- Managing user access and permissions
- Disabling user accounts
- Unlocking locked user accounts
- Resetting user passwords
- Troubleshooting Active Directory trust relationship failures
- Managing department-specific user configurations

I also practiced organizing users by department using Organizational Unites so that different 
departments could receive appropriate configurations and permissions. 

## Help Desk Scenarios
I used the lab environment to practice common IT Support and Help Desk scenarios, including:

- Locked user accounts
- Password reset requests
- Disabled user accounts
- User access and permission issues
- Active Directory trust relationship failures
- Basic Windows client troubleshooting

## Networking and DNS Troubleshooting
I also used the lab to practice troubleshooting common network suport issues, including:

- No internet connectivity
- Wi-Fi connected but no internet access
- IP address conflicts
- DNS resolution failures
- IPv4 configuration
- DNS connectivity
- Client-to-server connectivity
